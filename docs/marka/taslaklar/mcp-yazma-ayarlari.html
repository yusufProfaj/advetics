Claude Code'a bağla

Komutu terminalde bir kez çalıştır. Sonra Claude Code'da /mcp ile bağlantıyı gör.

claude mcp add --transport http --scope user advetics https://advetics.com/api/mcp --header "Authorization: Bearer adv_rw_ANAHTARINIZ"
"onayla" aracına her zaman izin verme. Claude Code her onayda "izin veriyor musun?" diye sorar. Bu soru, işlemin senin sözünle yapıldığının ikinci güvencesi.
